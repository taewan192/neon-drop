NEON DROP · 모바일 블록 게임

neon-drop.html을 브라우저에서 열면 바로 플레이할 수 있습니다.
외부 라이브러리, 이미지 다운로드, 인터넷 연결이 필요 없는 단일 HTML 파일입니다.
휴대폰에서 파일 미리보기만 표시되면 HTML을 실행할 수 있는 브라우저로 열어 주세요.
온라인 주소로 배포된 버전은 아닙니다.

조작
- ← / → : 이동. 길게 누르면 연속 이동
- ↓ : 천천히 내리기
- ↻ : 시계 방향 회전
- 바로 내리기 : 고스트 블록 위치로 즉시 착지
- HOLD : 블록 보관/교환. 블록을 착지시키기 전에는 한 번만 가능
- 보드 탭 : 회전
- 보드 좌우 스와이프 : 이동
- 보드 아래 스와이프 : 즉시 착지
- 키보드 : 방향키, Space 착지, C 보관, P 또는 Esc 일시정지

게임 규칙
- 10 × 20 보드, 7종 블록의 무작위 가방 방식
- 1/2/3/4줄 삭제 기본 점수는 100/300/500/800 × 현재 레벨
- 연속 줄 삭제 보너스와 낙하 점수
- 10줄 삭제마다 레벨 상승 및 낙하 속도 증가
- 다른 앱/탭으로 이동하거나 창 포커스를 잃으면 자동 일시정지
- 최고 기록은 브라우저의 로컬 저장소에 보관 (저장소 차단 시 현재 실행 동안만 유지)

검증: 게임 규칙 자동 테스트와 Edge/Chromium 모바일 화면 에뮬레이션 완료.
실물 Android/iPhone 기기에서의 검증은 수행하지 않았습니다.

설정 업데이트
- 기본 언어: 영어
- 메인 화면 소리 버튼 옆 톱니바퀴 버튼에서 설정 열기
- 라이트(화이트)/다크 모드 즉시 적용
- 지원 언어: 영어, 한국어, 일본어, 중국어 간체, 러시아어, 힌디어, 프랑스어, 필리핀어, 태국어, 베트남어
- 테마와 언어는 이 브라우저에 자동 저장됩니다.
- 업데이트가 보이지 않으면 게임 페이지를 새로고침하세요.
